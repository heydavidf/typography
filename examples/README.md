# Specimens and representative briefs

All copy, records and event details are fictional. Open the HTML files directly; there are no remote requests, scripts or bundled fonts. `specimens.css` owns their editable styles. Screenshots, when provided, illustrate a particular rendered state, not every platform.

## Before and after

[before-after.html](before-after.html) compares identical content and the same Georgia/Times New Roman/serif stack. The before uses 14px body text at 1.18 leading and little separation between roles. The after uses 18px body text at 1.65, a stronger 44px heading, 62ch maximum prose measure and space that groups a heading with its following paragraph. The responsive comparison stacks at narrow widths; the after heading becomes 35.2px. These are CSS settings at a default 16px root, not guaranteed rendered glyph sizes or a universal recipe. No copy edits, new fonts or scientific readability claims are involved.

## Existing-brand interface

Copy [interface.html](interface.html) and its CSS. Brand authority for this synthetic task: retain Arial/Helvetica/sans-serif, the green palette and the existing wording. Refine label/value hierarchy, numeric scanability, error text and form controls. Do not replace the family or turn the task into a rebrand. Deliver exact roles and settings and inspect controls with keyboard focus and editable text. Tabular numerals depend on font support; the CSS request alone does not establish identical figure advances. The controls are static demonstration controls, not a real invoice workflow.

## Missing prerequisites and checks

If a brand specifies a licensed font file that is unavailable, keep that choice in the proposal, request the authorized asset and label the fallback preview. Do not download an unauthorized substitute or claim to have rendered the missing font. Without a browser, report visual review as outstanding.

For each specimen, inspect 1280px and 320px widths, increased copy/long tokens, fallback stacks, controls where present and the combined user text-spacing override from [web delivery](../references/web-delivery.md). Probe a 200% root font size as one check, but label it separately from real browser zoom. Check effective contrast pairs and actual content/geometry; these are targeted checks, not complete WCAG conformance. System stacks have no loading event to fail: remove the preferred family to exercise alternate fallback layout. For a project with actual `@font-face` assets, separately test blocked and successful loading.
